# 回购与股权激励合并面板（已确认）

保留现有平台及其他面板，将第五面板改为“回购与股权激励”。现有首次实施公告回测不改变，另增加回购用途研究与按日归类。

## 归类

- 只有回购披露，包括拟用于股权激励的回购，仍归回购。
- 必须有对应方案的明确关联证据，才在激励预案公告日起进入“股权激励·待实施”，首次实施公告日起进入“股权激励·已实施”。不能用同公司旧激励计划替代对应关系。
- 缺乏对应关系保留“关联未核实”。独立激励方案仍可展示，不能凭空将回购批次转入。
- 回购用途和回购方式分开；股权激励注销单列，不当作普通注销减资。混合用途与未知用途单列，不强行拆分金额。
- 归类变化不是交易信号。原激励策略仍在首次实施公告后入场。

## 新回购研究口径

按公司与首次预案日识别可辨认回购方案。只有在现存明细公告日可确认的用途与方式可以进入历史筛选，不把最新用途回填到首次预案日。使用每个可辨认方案最早现存明细披露作为一次观察事件，次一市场交易日尝试买入；不得称为完整的首次回购预案策略。首次预案日缺失、同方案同日用途/方式冲突的记录只展示，不用于生成回测事件。

按用途、方式、持有期、起止日、仓位筛选，复用经验证的固定本金引擎。无融资、零交易费用、自然月持有、无可买价格跳过、无法卖出顺延。每日股票池、持仓、交易、净值、万得全A、年度与市场阶段统计、两期变化及 XLSX 下载均保留。

## 展示及边界

同一入口提供“说明 / 回购归类与用途 / 回购策略 / 股权激励策略”。分类台账支持日期、用途、方式、阶段及代码查询，并按方案明细披露关联依据。数据为导出样本，不宣称全市场完整；不以最终方案状态回填历史。ROE只说明用途差异，不生成没有财务依据的数值影响。
