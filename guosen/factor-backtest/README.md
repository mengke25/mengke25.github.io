## 公开安全模型（重要）

本页**可托管在公开仓库（如 GitHub Pages）**，因为：

- **无数据文件**：不引用任何本地数据文件；因子库 `curated.sqlite`、收益序列 `returns.blob` 仅作为**概念名称出现在正文文字中**，从不出现在任何 `href` / `src` 中。
- **无收益数值**：不包含任何收益、回撤、换手等实际结果数字。
- **无脚本、无 iframe、无外链**：除唯一的 `<link href="./styles.css">` 外，不加载任何资源；不存在 `<script>`、`<iframe>` 或 `http(s)://` 外链。

> 完整的回测引擎、完整组合（累计交叉、任意 N）与实际收益、风险数值，均在**本地便携应用**中产出与运行，不在公开页中暴露。
