④ 本地便携应用 vs GitHub Pages

明确边界：完整组合与实际结果只在本地产出，公开页只讲方法与结构。

本地便携应用

  • 完整回测引擎：PIT 对齐、下一交易日执行、万得全A 股票池与基准。
  • 支持累计交叉、任意 N 组合，并产出年内最大回撤、月级市场状态分层等实际结果。
  • 使用本地数据：因子库 curated.sqlite、收益序列 returns.blob。
  • 含完整收益与风险数值；运行于本地，非公开部署。

GitHub Pages 公开页（本页）

  • 静态研究地图，公开可访问、可分享。
  • 仅方法说明与因子清单 / 计数，以及能力矩阵的结构标注。
  • 不含数据文件，不含任何收益数值。
  • 公开安全：可在公开仓库托管。

⑤ 关键定义

贯穿回测全程的若干关键术语（仅概念定义，不含数值）。

PIT（Point-in-Time）
因子值严格按其在历史时点“当时可得”的状态取用，避免用未来才披露的信息解释过去的收益，即规避“未来函数”。
下一交易日
信号在 T 日（当前交易日）生成，回测在 T+1 下一交易日按既定规则执行，确保结果具备可执行性。
万得全A
作为回测基准与可投股票池口径，覆盖 A 股全市场，用于收益比较与样本界定。
年内最大回撤
以自然年为窗口衡量的最大回撤，刻画当年从峰值到谷底的最坏回撤幅度。
月级市场状态
按月聚合判定的市场状态（如牛市 / 熊市 / 震荡），用于在不同环境下分层评估因子表现。
